### Задача 1. Розворот цілого числа (15 балів)
**Клас:** `olympiad_v1.Task1`  
**Сигнатура:** `public static int reverseNumber(int number)`

#### Суть завдання
Реалізуйте метод, який розвертає цифри цілого числа у зворотному порядку.
* Якщо вхідне число від'ємне, знак мінус (`-`) має зберегтися спереду результату.
* Нулі, які опиняються на початку розвернутого числа, відкидаються.

#### Обмеження
* Заборонено перетворювати число у `String`, `StringBuilder` чи масив символів (`char[]`) — використовуйте лише арифметичні операції (`%` та `/`).

#### Приклади
| Вхід (`number`) | Результат | Пояснення |
| :--- | :--- | :--- |
| `1234` | `4321` | Звичайний розворот |
| `-580` | `-85` | Мінус зберігається, початковий нуль відкидається |
| `1000` | `1` | Усі нулі на початку результату відкидаються |
| `0` | `0` | Нуль залишається нулем |

### Задача 2. Пропущене число в послідовності (25 балів)
**Клас:** `olympiad_v1.Task2`  
**Сигнатура:** `public static int findMissingNumber(int[] numbers)`

#### Суть завдання
На вхід подається непустий масив цілих чисел `numbers` довжиною $N$. Відомо, що масив містить різні числа з діапазону від `1` до `N + 1`, але рівно одне число з цього діапазону відсутнє. Знайдіть і поверніть це пропущене число.

#### Обмеження
* Числа в масиві можуть бути розташовані у довільному (невідсортованому) порядку.
* Гарантується, що `numbers != null` і `numbers.length >= 1`.

#### Приклади
| Вхід (`numbers`) | Результат | Пояснення |
| :--- | :--- | :--- |
| `{3, 1, 4, 5}` | `2` | Довжина 4 → діапазон `1..5`, відсутнє число `2` |
| `{2, 3}` | `1` | Довжина 2 → діапазон `1..3`, відсутнє число `1` |
| `{1, 2, 3}` | `4` | Довжина 3 → діапазон `1..4`, відсутнє число `4` |
| `{2}` | `1` | Довжина 1 → діапазон `1..2`, відсутнє число `1` |

### Задача 3. Система керування парковкою (40 балів)
**Клас для реалізації:** `olympiad_v1.task_3.ParkingLot`

#### Суть завдання
У пакеті `olympiad_v1.task_3` вже створені два допоміжні класи-моделі:
* **`Vehicle`** — описує автомобіль:
    * `getLicensePlate()` — державний номер (`String`);
    * `getSize()` — габарит автомобіля (`int`: `1` — малий, `2` — середній, `3` — великий).
* **`ParkingSpot`** — описує паркомісце:
    * `getSpotNumber()` — унікальний номер місця (`int`);
    * `getSpotSize()` — розмір місця (`int`: `1` — мале, `2` — середнє, `3` — велике);
    * `getParkedVehicle()` — посилання на припаркований `Vehicle` (або `null`, якщо місце вільне);
    * `setParkedVehicle(Vehicle vehicle)` — призначає або знімає автомобіль із місця.

У класі `ParkingLot` паркомісця зберігаються у звичайному масиві `ParkingSpot[] spots` (передається через конструктор). Використовуючи **лише звичайні масиви та цикли** (без колекцій `List` / `ArrayList`), реалізуйте 3 методи:

1. **`public boolean parkVehicle(Vehicle vehicle)`**  
   Розміщує автомобіль на парковці:
    * Якщо `vehicle == null` або масив `spots == null` — повертає `false`.
    * Автомобіль може встати лише на вільне місце (`spot.getParkedVehicle() == null`), розмір якого не менший за габарит авто (`spot.getSpotSize() >= vehicle.getSize()`).
    * Серед усіх підходящих вільних місць необхідно обрати **найменше за розміром** (наприклад, якщо приїхало мале авто `size = 1`, а вільними є велике `size = 3` і мале `size = 1`, авто має зайняти саме `size = 1`).
    * Якщо підходящих місць з однаковим мінімальним розміром декілька — обрати **перше за порядком у масиві `spots`**.
    * Призначити авто обраному місцю через `setParkedVehicle(vehicle)` і повернути `true`. Якщо підходящих місць немає — повернути `false`.

2. **`public boolean leaveSpot(int spotNumber)`**  
   Звільняє паркомісце за його номером:
    * Знаходить у масиві `spots` місце з номером `spotNumber`.
    * Якщо місце знайдено і воно зайняте (`getParkedVehicle() != null`), звільняє його (`setParkedVehicle(null)`) і повертає `true`.
    * Якщо місця з таким номером не існує або воно вже вільне — повертає `false`.

3. **`public int getAvailableSpotsCount(int size)`**  
   Повертає кількість вільних місць (`getParkedVehicle() == null`), розмір яких (`getSpotSize()`) точно дорівнює переданому значенню `size`.
